# 라이준:한글탐험

라이준 모험 지도에서 한글 탐험과 숫자·도형 모험을 고를 수 있는 로컬 게임 프로젝트입니다.

## 실행

Node.js가 설치된 환경에서 다음 명령을 실행합니다.

```sh
node serve.cjs
```

- [라이준 모험 지도](http://127.0.0.1:8080/)
- [기존 숫자·도형 기록 이전 안내](http://127.0.0.1:8081/)
- [한글 1화 · ㄱ 친구들](http://127.0.0.1:8082/)

게임 자산은 로컬 파일로 제공됩니다. 숫자·도형은 첫 실행에서 캐시를 준비한 뒤 오프라인으로 열 수 있습니다.
